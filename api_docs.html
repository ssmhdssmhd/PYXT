视频解析 API 文档

提供视频链接解析服务，支持多平台视频网站

GET POST /api/parse
▼

解析视频链接

解析视频网站链接，返回可播放的视频源地址

📥 请求参数

▼
参数名 类型 必填 说明
url string 必填 视频页面链接
show_url string 可选 失败时是否返回URL，1=是，0=否，默认=1

📤 响应参数

▼
参数名 类型 说明
code integer 状态码：200=成功，404=未找到，500=错误
msg string 返回消息
title string 视频标题
type string 视频类型：m3u8、mp4 等
url string 视频播放地址
from string 原始视频链接
time float 解析耗时（秒）

▼
cURL 
# GET 请求
curl "http://your-server-ip:5000/api/parse?url=https://www.iqiyi.com/v_xxx.html&show_url=1"

# POST 请求
curl -X POST http://your-server-ip:5000/api/parse \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.iqiyi.com/v_xxx.html","show_url":"1"}'
Python 
import requests

JavaScript 
// Fetch API (GET)
fetch('http://your-server-ip:5000/api/parse?url=https://www.iqiyi.com/v_xxx.html&show_url=1')
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.error('Error:', error));

// Fetch API (POST)
fetch('http://your-server-ip:5000/api/parse', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify({
        url: 'https://www.iqiyi.com/v_xxx.html',
        show_url: '1'
    })
})
.then(response => response.json())
.then(data => console.log(data))
.catch(error => console.error('Error:', error));

// Axios
axios.get('http://your-server-ip:5000/api/parse', {
    params: {
        url: 'https://www.iqiyi.com/v_xxx.html',
        show_url: '1'
    }
})
.then(response => console.log(response.data))
.catch(error => console.error('Error:', error));
Java 
import java.net.http.*;
import java.net.URI;

public class VideoParserClient {
    public static void main(String[] args) throws Exception {
        String url = "http://your-server-ip:5000/api/parse?url=https://www.iqiyi.com/v_xxx.html&show_url=1";
        
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create(url))
            .GET()
            .build();
        
        HttpResponse response = client.send(request, 
            HttpResponse.BodyHandlers.ofString());
        
        System.out.println(response.body());
    }
}
PHP 
<?php
// GET 请求
$url = "http://your-server-ip:5000/api/parse";
$params = [
    'url' => 'https://www.iqiyi.com/v_xxx.html',
    'show_url' => '1'
];

$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, $url . '?' . http_build_query($params));
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = curl_exec($ch);
curl_close($ch);

$result = json_decode($response, true);
print_r($result);

// POST 请求
$url = "http://your-server-ip:5000/api/parse";
$data = json_encode([
    'url' => 'https://www.iqiyi.com/v_xxx.html',
    'show_url' => '1'
]);

$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, $url);
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, $data);
curl_setopt($ch, CURLOPT_HTTPHEADER, ['Content-Type: application/json']);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = curl_exec($ch);
curl_close($ch);

$result = json_decode($response, true);
print_r($result);
?>
C# 
using System;
using System.Net.Http;
using System.Threading.Tasks;

class Program
{
    static async Task Main(string[] args)
    {
        using var client = new HttpClient();
        string url = "http://your-server-ip:5000/api/parse?url=https://www.iqiyi.com/v_xxx.html&show_url=1";
        
        var response = await client.GetAsync(url);
        var content = await response.Content.ReadAsStringAsync();
        
        Console.WriteLine(content);
    }
}

📌 重要提示：

                        
• 将示例中的 your-server-ip 替换为你的服务器 IP 地址

                        
• 如果在本地测试，使用 localhost 或 127.0.0.1

                        
• 确保服务器防火墙已开放 5000 端口

                        
• 支持的视频平台：爱奇艺、腾讯视频、优酷、芒果TV 等
